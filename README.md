# Resume Villain
An AI-powered ATS resume analyzer and roast engine built with FastAPI and Google Gemini.
Install dependencies using `pip install -r requirements.txt` and configure `GEMINI_API_KEY` in `.env`.
Start the server by running `python -m uvicorn main:app --port 8000`.
Open `http://localhost:8000` in your browser to select your villain and upload your resume.
